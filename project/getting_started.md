# Getting Started

## Welcome to the Lab

In this lab, you will set up a complete Amazon S3 infrastructure step by step. By the end of this lab, you will have:

- Three S3 buckets up and running
- A static website hosted on S3 that you can open in your browser
- Automatic replication of objects from one bucket to another
- Lifecycle rules that save you money automatically

## What You Will Do

| Exercise | What You Will Build |
|---|---|
| Exercise 1 | Create your S3 buckets |
| Exercise 2 | Set up bucket policies |
| Exercise 3 | Configure lifecycle rules |
| Exercise 4 | Set up replication between buckets |
| Exercise 5 | Host a static website on S3 |

## Before You Begin

Make sure you have:

- Logged in to your **AWS Account**
- Opened the **AWS Management Console**
- Selected your preferred **AWS Region**

## Estimated Time

Approximately **60 minutes**
